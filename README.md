# Form public demo

Fictional, read-only storefront demonstration by NAADRA LLC. Locally authored
examples; no live AI, account, upload or connected checkout. Reference imagery
and font credits are on credits.html.

Deploy as one Static Site, build command `sh build.sh`, output directory `_site`.
No service/container, database, secret or environment variable is required.
Use 404.html for errors, never an index.html catchall. Keep automatic deployments
off during acceptance. The full private Form application is not in this repository.
